# Zephyrus

Cohesive, test-driven PHP 8.4+ framework core.

## Status
Early bootstrap on `dev` branch.

## Goals
- Single coherent architecture and naming model
- Strong unit tests by default
- Typed, section-based configuration objects
- Attribute-first routing and controller model
- Lean core that can be extended (Web3 shipped as extensions)

## Principles
- Explicit over magical
- Secure by default
- Fast feedback through tests
- Backward migration path from Zephyrus v1 for real projects like CodeQuill
